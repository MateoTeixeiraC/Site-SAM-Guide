# Site-SAM-Guide
Le site pour le projet ANR SAM-Guide

INFORMATIONS IMPORTANTES :

- La page actualités peut être alimentée à volonté, vous trouverez dessus un commentaire d'explication.

- La page annonces (pour offres professionnelles) est actuellement vierge. 
Si vous souhaitez cacher cette page, vous trouverez à la fin de chaque fichier CSS cette section : 

/* .nav-links a[href*="annonces"],
footer a[href*="annonces"] {
    display: none !important;
} */

Il vous suffit de supprimer les /* de commentaire dans chaque fichier CSS pour mettre en effet et cacher les liens vers la page Annonces.

- Lorsque vous faites une modification sur un fichier HTML, n'oubliez pas de la faire aussi sur la version Anglaise du fichier.
